Пользователи и права

Администратор имеет полный доступ ко всем проектам. Для остальных права задаются по каждому проекту: нет доступа / чтение / редактирование. Изменения применяются сразу.
Новый пользователь
Новому пользователю будет предложено сменить пароль при первом входе.

Обновление приложения

Код приложения обновляется из git-репозитория, из которого оно установлено. Данные проектов, пользователи, config.json и .env не затрагиваются. После обновления сервер перезапустится, пользователям хватит обновить страницу.
