# Стартовые данные (необязательно)

В репозитории данных нет: после установки приложение пустое, проекты создаёт администратор
(«+ Проект» или «📂 Загрузить конфигурацию»).

Если есть исходный однофайловый планировщик (`capacity_planner*.html`), из него можно получить
стартовый проект:

```bash
node scripts/extract-seed.js путь/к/capacity_planner.html seed/release-2026.json
```

Скрипт проверит контрольные числа и запишет `seed/release-2026.json`. Если на сервере ещё нет
проектов, при следующем запуске он создаст из сида проект. Кроме того, станут доступны кнопка
«↺ Сбросить» и вариант «Копия стартовых данных» при создании проекта.
Файлы `seed/*.json` в git не попадают.
